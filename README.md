# Ultrasound Transducer Simulation

Hardcoded Python simulation of an ultrasound transducer for procedural applications.

## Features
- **Flexible Material Properties:** Easily introduce new piezoelectric materials and custom physical attributes.

## Requirements
- Python 3.9+

## Commit Naming Conventions

Please follow the format below when committing changes:

` <type>: <short descriptive action under 25 words> `

### Commit Types
* **`feat`**: Add a new feature or code modification
* **`fix`**: Fix a bug or logic error
* **`refactor`**: Code restructuring without changing the output
* **`docs`**: Documentation changes (e.g., updating the README)
* **`chore`**: Maintenance work, deleting unused files, or dependency updates

### Examples
* `feat: add new piezoelectric material preset`
* `fix: correct wave propagation velocity calculation`
* `docs: update setup steps in README`
